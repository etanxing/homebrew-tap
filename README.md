# etanxing Homebrew Tap

## 安装轻词

```sh
brew install --cask etanxing/tap/qingdict
```

需要 Apple Silicon Mac 和 macOS 13 或更新版本。

该安装配置只下载编译好的应用，不包含应用源码。应用介绍、安装说明和版本下载见 [qingdict-releases](https://github.com/etanxing/qingdict-releases)。

## 更新

```sh
brew update
brew upgrade --cask etanxing/tap/qingdict
```

## 卸载

```sh
brew uninstall --cask qingdict
```
